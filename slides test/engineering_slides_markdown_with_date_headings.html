Agenda 11/18/25

Criteria 1 (Developing) 2 (Approaching Standard) 3 (Meets Standard) 4 (Exceeds Standard)
I. Physical Accuracy & Measurements Model lacks recognizable scale or realistic proportions. Measurements, if used, are arbitrary or highly inaccurate. Model has generally realistic proportions, but key components (e.g., wheels, doors, windows) are clearly out of proportion or measurement is inconsistent. Model adheres to a consistent, realistic scale for a small electric car. Key component dimensions are estimated reasonably and consistently within the model (e.g., wheel diameter vs. body length). Model is designed using physically accurate measurements (e.g., drawing from known vehicle dimensions, or calculating realistic dimensions based on human factors/engineering principles). Measurements are precise and consistently applied .
II. Model Completeness & Detail Model is rudimentary and lacks essential features (e.g., missing wheels, undefined windows). The overall form is blocky or abstract. Model includes all essential exterior features (wheels, main body, windows) but lacks finer details. Features are simple and geometric. Model includes all essential exterior features and basic secondary details (e.g., headlights, door lines, mirrors). Surfaces are generally clean and well-defined.
