## Key terms

* **Browser**: the program you use (Google Chrome, Safari) to access the web. This reads the HTML and CSS and makes it readable to humans.

* **HTML code** (HyperText Markup Language): the building blocks of the web. This is where you will put the content of your site.

* **CSS** (Cascading Style Sheets): the visuals of the site.

## Notes

HTML code is made up of **tags**:

    <img src="image.png"> 

will make an image on your page.

    <a href="https://google.com">

will make a link (more on this later). 

Many tags need to be "opened" and "closed." An "opening" tag looks like this:

    <b>

A "closing" tag begins with a slash, like this:

    </b>

You can surround text with "opening" and "closing" tags to apply some effect. For instance,
    
    <b>This will make bold text.</b>

Notice that we begin with \<b\> and end with \</b\>.

The most difficult example is a link.  Here is what a full link looks like:

    <a href="https://google.com">This is a link</a>

Let's break it down.

    <a href=

This tells us that it is a link

    "https://google.com" 

is the "URL"—the address to the site we want to link to.

    This is a link

This is the text that the user can click on.

    </a>

This is the closing tag, that tells the web browser to stop making the link.

When we put it together, it looks like this: <a href="https://google.com">This is a link</a>

For your site, you will need:

    <h1>This is a heading</h1>
    <p>This is a block of text</p>

That clearly describe what your app does and how it will make money. You can reuse text from any of the assignments you have already done.
